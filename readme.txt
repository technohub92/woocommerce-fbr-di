Official Pakistani FBR PRAL Digital Invoicing (SRO 350/2024 & SRO 1832/2024) integration for WooCommerce. Automates digital fiscal invoices, verification QR codes, and buyer NTN/CNIC compliance.

== Description ==
Connect your WooCommerce store directly to the official FBR PRAL Digital Invoicing Gateway. This plugin automatically generates FBR-compliant digital sales invoices on checkout or order completion, appends official Tax Asaan QR codes to customer receipts, and manages buyer NTN/CNIC tax fields.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/fbr-digital-invoicing-woocommerce` directory, or install the .zip directly via WordPress Plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to `WooCommerce > Settings > FBR Digital Invoicing`.
4. Enter your API Key and click 'Test Connection & Auto-Sync Profile'.
